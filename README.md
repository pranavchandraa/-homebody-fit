# HomeBody Training Log

A mobile-first, installable bodyweight workout tracker.

## Publish free with GitHub Pages
1. Create a **public** GitHub repository named `homebody-fit`.
2. Upload all files in this folder to the repository root (including `.nojekyll`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for deployment. Your site URL will be `https://YOUR-USERNAME.github.io/homebody-fit/`.

The site is public. Workout checkmarks are stored locally in the browser on the device and are not sent to a server.

## Add to Android home screen
1. Open the published HTTPS URL in Chrome.
2. Tap the three-dot menu.
3. Tap **Add to Home screen** or **Install app**.
4. Confirm. The HomeBody icon will appear on your home screen.

Progress is stored in local browser storage. Clearing browser data can erase it.
